Build Geometry · five solids, five organ-jobs

Every organ of a node gets a Platonic shape, so the architecture reads at a glance: a cube (the working unit) carrying a dodecahedron (its memory) inside it, gated by an octahedron (verify — the cube read inside-out), exploring via an icosahedron (dual of memory — you explore from what you remember), born as a self-dual tetrahedron. The geometry is real (Euler's V−E+F=2, the duality pairs); a node is mature only when all five are held, and the two that persist a self — verify + remember — are scarce.

Is a node mature?

Why the dodecahedron is memory: memory must be aperiodic — perfect recall is no compression, which carries no lesson. The dodecahedron is the golden-ratio solid, the shape that will not tile/repeat, so it is the store that carries meaning. Why verify + remember are scarce: they are the two shapes that persist a self — a node that builds, is born, and explores but never verifies or remembers is provably-fit and a cripple. Composes fallkard (the §26 lifecycle), mesh-self (the node), dream-gate (memory that grows). The quine — a node that builds itself — is the design language over the real geometry, kept as lens.
